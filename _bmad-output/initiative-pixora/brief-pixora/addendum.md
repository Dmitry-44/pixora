# Addendum: Pixora

Подробности, которые пригодятся в PRD и архитектуре, но слишком детальны для самого брифа.

## Технические ограничения

### Провайдер моделей: Polza.ai
- Это агрегатор: один API даёт доступ к сотням моделей, в том числе для генерации изображений. API совместим с OpenAI SDK (`base_url = https://polza.ai/api/v1`). Документация: https://polza.ai/docs/api-reference/introduction
- Отсюда следствие: обогащать промт можно LLM-моделью у того же провайдера с тем же ключом.
- Если запрос завершился ошибкой, деньги не списываются, его можно безопасно повторить. Исключение: если соединение оборвалось по таймауту на нашей стороне, уже сгенерированная часть оплачивается. Таймаут на запрос 600 секунд.
- Важные ошибки:
  - 402: закончились деньги или исчерпан лимит расходов;
  - 403: запрос отклонила модерация, бот должен показать пользователю понятное сообщение;
  - 429: превышен лимит запросов, у Polza свой лимит к модели в минуту и в сутки.
- Максимальный размер файла 50 MB.
